## Publication controls and review

The repository owner explicitly authorized the public Apache-2.0 source release, repository configuration, immutable tag, and GitHub Pages publication. Active rules protect `v*` tags against update/deletion and `main` against deletion/non-fast-forward updates. The `github-pages` environment restricts deployment to `main` and required the owner's approval, which was granted before deployment.

The live Claude peer's official code review approved the release commit at confidence 92/100. The final report retains one nonblocking warning and five informational follow-ups, with no critical findings. They concern future identity-validator coverage, optional planning-harness portability, pinned CLI prompt behavior, and guardrail maintenance. See the [Phase 4 review record](https://github.com/brady-zip/afferent/blob/main/.planning/phases/04-hosted-production-release/04-REVIEW.md) for exact findings and limitations.
