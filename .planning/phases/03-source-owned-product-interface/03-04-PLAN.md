## Trust Boundaries

| Boundary                                                     | Description                                                                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| Browser admin controls -> trusted host mutations             | UI capability and form values are untrusted; host wrappers derive authority and scope every call. |
| Destructive confirmation -> merge/archive/publish operations | Consequential intent must be explicit without being mistaken for authorization.                   |

## STRIDE Threat Register

| Threat ID       | Category             | Component                    | Severity | Disposition | Mitigation Plan                                                                                                 |
| --------------- | -------------------- | ---------------------------- | -------- | ----------- | --------------------------------------------------------------------------------------------------------------- |
| T-03-12         | Spoofing / Elevation | admin screen                 | critical | mitigate    | No authority props; server capability and per-call trusted wrappers remain final, with forged-state tests.      |
| T-03-13         | Tampering            | merge confirmation           | high     | mitigate    | Exact source-title typed confirmation plus server conflict result; no optimistic relation update.               |
| T-03-14         | Repudiation          | moderation/editorial actions | medium   | mitigate    | UI displays server mutation outcomes and existing append-only activity; it fabricates no local success/history. |
| T-03-15         | Tampering            | changelog publication        | high     | mitigate    | Only explicit publish/unpublish hook calls; tests reject status-driven/local automatic publication.             |
| </threat_model> |
