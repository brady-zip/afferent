<threat_model>

## Trust Boundaries

| Boundary                         | Description                                                                  |
| -------------------------------- | ---------------------------------------------------------------------------- |
| Source tree -> generated release | Version and digest drift must stop before artifacts leave CI.                |
| GitHub workflow -> npm OIDC      | npm trusts one exact repository/workflow identity and short-lived job token. |
| Preview -> production            | Convex keys, backends, Vercel environments, and data are strictly separate.  |

## STRIDE Threat Register

| Threat ID       | Category               | Component                  | Severity | Disposition | Mitigation Plan                                                                        |
| --------------- | ---------------------- | -------------------------- | -------- | ----------- | -------------------------------------------------------------------------------------- |
| T-04-34         | Tampering              | generated release surfaces | high     | mitigate    | Deterministic generation and clean-tree/version/digest verification.                   |
| T-04-35         | Spoofing               | npm trusted publisher      | critical | mitigate    | Exact repository/workflow registration, cloud runner, OIDC, and protected environment. |
| T-04-36         | Elevation of Privilege | release workflow           | critical | mitigate    | Minimal permissions, trusted triggers, no fork secrets, and no long-lived npm token.   |
| T-04-37         | Information Disclosure | preview credentials        | critical | mitigate    | Separate preview key/backend and trusted-event environment protection.                 |
| T-04-38         | Repudiation            | published tarball          | high     | mitigate    | Publish the checksum-matched tested artifact with npm provenance.                      |
| </threat_model> |

The release-candidate verifier must parse workflow semantics and build the immutable artifact set locally without publishing. It fails on version drift, generated diffs, raw TS exports, wrong repository/workflow identity, toolchain floors, token use, missing OIDC, preview/production secret overlap, or reordered downstream deployment.
</verification>
