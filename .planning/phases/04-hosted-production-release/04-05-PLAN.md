<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Published artifact -> hosted app | Demo must consume the same package and registry source adopters receive. |
| Host binding -> component UI | Function references may change by environment; authority values may not enter components. |
| Lifecycle transition -> rendered cache | A retired generation must not remain visible after environment or generation switch. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-19 | Tampering | demo artifact provenance | high | mitigate | Pin tarball/registry digests and reject repository-relative product imports. |
| T-04-20 | Information Disclosure | stale UI cache | high | mitigate | Remount providers on environment/lifecycle epoch and test no stale-data flash. |
| T-04-21 | Spoofing | browser authority props | critical | mitigate | Generate bindings with no `userId`, `isAdmin`, `scopeId`, owner, or generation inputs. |
| T-04-22 | Denial of Service | reset interaction | medium | mitigate | Confirm destructive reset, surface bounded busy state, and rely on server logical-owner throttle. |
| T-04-23 | Repudiation | candidate origin | medium | mitigate | Persist and assert exact package and registry digests for each prepared candidate. |
</threat_model>
