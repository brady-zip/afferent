<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser write -> host quota | Only a verified logical owner and server-resolved active generation may consume quota. |
| Host maintenance -> component cleanup | Broad deletion authority is internal-only, explicit, bounded, and scope-specific. |
| Retired generation -> active data | Cleanup must prove retired state and version before every batch. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-14 | Elevation of Privilege | cleanup target | critical | mitigate | Resolve targets from leased retired host records; expose no public scope/cursor input. |
| T-04-15 | Tampering | active generation | critical | mitigate | Compare generation state/version on every cleanup batch and adversarially assert active data invariance. |
| T-04-16 | Denial of Service | public sandbox storage | high | mitigate | Enforce root and total-footprint limits with bounded indexed usage reads. |
| T-04-17 | Spoofing | reset quota bypass | high | mitigate | Throttle reset by verified logical owner outside replaceable physical scopes. |
| T-04-18 | Information Disclosure | quota DTO | medium | mitigate | Return only versioned safe codes/counts/copy with no authority identifiers. |
</threat_model>
