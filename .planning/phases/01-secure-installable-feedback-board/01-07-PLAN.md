## Trust Boundaries

| Boundary | Description |
|---|---|
| Provider helper seam -> fixture factory | Test seams must preserve the production helper contract and may not accept browser values. |
| Better Auth component -> Afferent fixture | Only a session-validated stored user can become an Afferent actor. |
| Browser -> host factory client | Intent fields are untrusted and authority is recomputed on every operation. |
| Host client -> isolated Afferent component | Scope and actor facts must be server-derived before component invocation. |
