## Decisions Made

- The optional read resolver returns provider-neutral `VerifiedActor | null`; no client argument, cache generation, or browser state can supply viewer authority.
- Actor resolution never creates or updates actor state during a query. A missing actor row is a normal anonymous-equivalent capability result.
- Withdraw availability mirrors the existing repeat-safe ownership enforcement exactly rather than inventing a stricter presentation policy.
- Minimal projections that offer no matching viewer actions remain unchanged.
