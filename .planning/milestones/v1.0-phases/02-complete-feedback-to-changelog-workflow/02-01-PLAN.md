## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser -> injected host refs | Untrusted filters/pagination cross into trusted host wrappers. |
| Host wrapper -> component | Server-derived scope/read authority enters isolated storage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-01 | Spoofing / Elevation | host feed wrappers | high | mitigate | Derive scope and read authentication on every call; browser validators contain no authority fields. |
| T-02-02 | Information Disclosure | feed indexes/filters | high | mitigate | Scope-leading selective indexes plus the single visibility key/predicate and two-scope tests. |
| T-02-03 | Denial of Service | pagination/ranking | medium | mitigate | Server cap `numItems`, stored ranking values, bounded helper pagination, and no read-time scans/decay. |
| T-02-04 | Tampering | React page accumulation | low | accept | Helper results remain canonical; hook tests reject a second accumulator/dedupe cache. |
</threat_model>
