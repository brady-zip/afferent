|----------|-------------|
| Anti-skip source checks -> claimed release evidence | Assertions must inspect the artifact where a key/text/scenario actually lives and cannot be satisfied by dead strings. |
| Mounted recovery action -> headless watch | Each click must re-execute only the originating binding/arguments, never a test-owned substitute. |

| Evidence-only closure -> verified product baseline | Tests may not mutate correct product source merely to satisfy a flawed oracle. |
