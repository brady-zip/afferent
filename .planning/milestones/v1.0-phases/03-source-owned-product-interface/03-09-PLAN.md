<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Copied public UI -> headless read state | Recovery may invoke only the query-owned retry already returned by the installed hook; it cannot invent authority or arguments. |
| Headless retry -> active subscription generation | A stale callback from the failed generation must never overwrite the retried generation. |
| Canonical UI -> generated consumer source | Public state copy and wiring must flow through deterministic generation, not hand-edited mirrors. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-32 | Elevation of Privilege | public retry controls | critical | mitigate | Expose only the existing bound watch retry; accept no client-supplied actor, admin, scope, or query authority. |
| T-03-33 | Tampering | retried watch state | high | mitigate | Retain the query layer's generation fence and test stale callback exclusion after recovery. |
| T-03-34 | Repudiation | public activity copy | medium | mitigate | Use the shared exhaustive domain formatter and mounted tests for every closed state instead of raw discriminant interpolation. |
| T-03-35 | Denial of Service | repeated retry | low | accept | Retry restarts only the matching bounded watch query and existing pending/loading state governs repeated interaction. |
</threat_model>
