<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → host Convex functions | Untrusted intent crosses into the application security boundary. |
| Host wrappers → isolated component | Verified actor/admin facts and hidden scope enter narrow component intents. |
| Package tarball → clean consumer | Only declared packed files may satisfy imports and codegen. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-04 | Spoofing | host wrappers | critical | mitigate | Omit authority fields from browser validators and derive actor/admin server-side on each call. |
| T-01-05 | Elevation of Privilege | admin capability | high | mitigate | Keep admin authorization independent from actor resolution and invoke it before every admin component call. |
| T-01-06 | Information Disclosure | DTO mappers | high | mitigate | Explicit return validators and mappers expose branded strings and safe display data only. |
| T-01-07 | Tampering | package artifact | high | mitigate | Build and install an absolute tarball in an external fresh consumer; reject source-root resolution. |
| T-01-08 | Denial of Service | listPosts | medium | mitigate | Use a scope-first index and a server-enforced bounded page size. |
| T-01-SC | Tampering | npm installs | high | mitigate | Install only the exact versions approved in Plan 01-01 and preserve the lockfile. |
</threat_model>
