## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser vote/comment intent → host wrapper | Untrusted post/comment IDs, text, and desired state enter authenticated wrappers. |
| Component mutation → membership/counter rows | Transactional invariants protect derived totals from tampering and retries. |
| Host erasure request → retained history | Privileged identity removal must not expose scope or corrupt relationships. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-15 | Tampering | vote membership/counter | high | mitigate | Exact unique membership lookup and atomic desired-state counter update with concurrency/reconciliation tests. |
| T-01-16 | Tampering | comment relationships | high | mitigate | Scope/post/root-parent validation before insertion and transactional count update. |
| T-01-17 | Elevation of Privilege | anonymizeActor | high | mitigate | Independent host admin authorization on every call; client claims absent from args. |
| T-01-18 | Information Disclosure | anonymized actor | high | mitigate | Clear display data, replace external key irreversibly, and emit generic DTO label only. |
| T-01-19 | Repudiation | retained history | medium | mitigate | Retain stable actor/content relationships and canonical memberships after erasure. |
| T-01-SC | Tampering | npm dependencies | high | mitigate | Keep Plan 01-01 approved versions and lockfile; introduce no unreviewed package. |
</threat_model>
